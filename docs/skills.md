# 🛠️ Skills do Projeto (Antigravity Skills)

Este repositório inclui a suíte completa de **Skills do Antigravity** localizadas na pasta `.gemini/skills/`. As skills definem diretrizes de arquitetura, desenvolvimento, testes, Java moderno, customizações do agente e UI generativa.

---

## 📌 Relação de Skills Incorporadas

| Skill | Diretório | Descrição |
| :--- | :--- | :--- |
| 🏛️ **especialista-arquiteto** | `.gemini/skills/especialista-arquiteto/` | Diretrizes de Arquitetura de Sistemas, DDD, Padrão Saga, CQRS, Persistência Poliglota, Zero Trust, DevSecOps, Chaos Engineering e RESTful APIs. |
| 💻 **especialista-dev** | `.gemini/skills/especialista-dev/` | Práticas de desenvolvimento, TDD (Red-Green-Refactor), POO (4 pilares), SOLID, DRY/KISS/YAGNI, Clean Code e padrões GoF. |
| ☕ **especialista-java** | `.gemini/skills/especialista-java/` | Java 17/21 LTS (`var`, Records, Virtual Threads), Spring Boot 3.x, Spring Cloud, Springdoc OpenAPI 3, MapStruct e GraalVM. |
| 🧪 **especialista-test** | `.gemini/skills/especialista-test/` | Estratégia de testes automatizados com JUnit 5 Jupiter, estrutura `@Nested` em 3 níveis, `@ParameterizedTest` com `@CsvSource` e Testcontainers. |
| ⚙️ **agy-customizations** | `.gemini/skills/agy-customizations/` | Guia completo do sistema de customizações do Antigravity (skills, rules, plugins, hooks e servidores MCP). |
| 📖 **antigravity-guide** | `.gemini/skills/antigravity-guide/` | Guia de referência do Antigravity CLI (`agy`), Antigravity IDE, Python SDK e sitemap da plataforma. |
| 🎨 **generative-ui** | `.gemini/skills/generative-ui/` | Padrões para renderização de componentes visuais interativos em HTML/Tailwind CSS inline ou em artefatos. |

---

## 🚀 Como Utilizar

As skills são carregadas automaticamente pelo Antigravity ao abrir o projeto e podem ser invocadas ou consultadas a qualquer momento durante o desenvolvimento.
